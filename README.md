# ConfluenceX'26 — Official Event Website

> **Next Generation of Chemical Innovation** | Ideas. Innovation. Impact.
> Organized by the Department of Chemical Engineering, VGEC, Chandkheda, Ahmedabad

---

## 📌 Project Overview

A **static single-page website** for **ConfluenceX'26**, a technical fest / innovation event hosted by the Chemical Engineering Department at Vishwakarma Government Engineering College (VGEC). The site will be deployed on **GitHub Pages** with zero backend dependencies.

**Tech Stack:** Pure HTML5 · Vanilla CSS3 · Vanilla JavaScript (no frameworks, no libraries except icons/fonts from CDN)

---

## 🎨 Design Theme

| Property | Value |
|---|---|
| **Theme** | Dark futuristic / chemical molecular innovation |
| **Primary Colors** | Deep navy `#0a0f2e`, Electric purple `#7c3aed`, Cyan accent `#06b6d4` |
| **Accent** | Gold `#f59e0b` for highlights and CTAs |
| **Typography** | `Outfit` (headings), `Inter` (body) — Google Fonts |
| **Background** | Animated floating molecular/hexagon particle canvas (JS Canvas API) |
| **Style** | Glassmorphism cards, gradient borders, glowing neon effects |
| **Animations** | Scroll-reveal fade-ins, hover glow effects, timeline step animations, animated counter numbers, floating particles |

## ⚙️ JavaScript Features

- `IntersectionObserver` → scroll-reveal animations on all sections
- `Canvas API` → animated floating hexagon/molecule particles on hero
- `Smooth scroll` → navbar link click
- `Countdown timer` → live days/hours/mins/secs to August 1, 2026
- `Active nav highlight` → updates on scroll
- `Animated counters` → stats like "500+ Students" count up on scroll
- `Hamburger menu toggle` → mobile nav
